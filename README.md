# 문서 도우미 다운로드

교실에서 사용하는 Windows 바탕화면 도우미입니다. HWP 파일을 HWPX로 바꾸거나, HWP·HWPX 문서를 PDF와 PNG로 저장할 수 있습니다. 아래 링크는 로그인 없이 최신 Windows x64 버전을 내려받습니다.

| 다운로드 | 어떤 파일을 받으면 되나요? |
| --- | --- |
| [독립 실행판 ZIP 다운로드](https://github.com/zeroboom92/document-buddy-downloads/releases/latest/download/DocumentBuddy-win-x64-standalone.zip) | 처음 사용하거나 PC에 설치된 .NET 버전을 모를 때 선택하세요. |
| [경량판 ZIP 다운로드](https://github.com/zeroboom92/document-buddy-downloads/releases/latest/download/DocumentBuddy-win-x64-lightweight.zip) | .NET 8 Desktop Runtime x64가 설치되어 있을 때 선택하세요. 기능은 독립 실행판과 같습니다. |

ZIP을 새 폴더에 모두 풀고 폴더 안의 **DesktopTools.exe**를 실행하세요. 사용 중인 버전을 업데이트할 때는 먼저 Windows 알림 영역에서 문서 도우미를 종료해 주세요.

문서를 캐릭터 위로 끌어오거나 파일을 끄는 중에 **Shift**를 누르면 변환할 형식을 고를 수 있습니다. PDF 변환에는 Google Chrome 또는 Microsoft Edge가 필요합니다.

[최신 버전과 변경 사항 보기](https://github.com/zeroboom92/document-buddy-downloads/releases/latest)
